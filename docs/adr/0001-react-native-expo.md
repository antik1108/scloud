# ADR 0001 — React Native (Expo) for the client app

- **Status:** Accepted (2026-11-23)
- **Supersedes:** the initial SwiftUI choice in the first draft of SPEC.md

## Decision
Build the app with React Native on Expo SDK 58 (development builds, expo-router, EAS), using
React Native Firebase for native Firebase SDKs. iOS ships first; Android builds from the same
codebase and must stay green in CI.

## Consequences
- One TypeScript codebase for iOS and Android; shared language with Cloud Functions.
- Expo Go cannot be used (native Firebase modules) — everyone needs a development build.
- Performance-critical imaging runs on the GPU via React Native Skia; face detection,
  segmentation and video composition need custom Expo native modules
  (`modules/lumio-vision`, `modules/lumio-video`) in Phases 3, 4 and 7.
- `ios/` and `android/` are generated by `expo prebuild` and gitignored; native changes go
  through config plugins only.
